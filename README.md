# Love Maths

Love Maths is a simple browser-based math game where players answer quick arithmetic questions and track their score. It is built with HTML, CSS, and vanilla JavaScript to practice core DOM manipulation and event handling.

## Live Demo

This project is meant to run locally. Open [index.html](index.html) in a browser.

## Features

- Randomized arithmetic questions
- Instant feedback for correct and incorrect answers
- Score tracking for right and wrong attempts
- Responsive layout for desktop and mobile

## How To Use

1. Open [index.html](index.html) in a modern browser.
2. Read the displayed question.
3. Enter your answer and submit.
4. Watch the score update and keep playing.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Development

No build tools are required. Edit the files and refresh the browser to see changes.

## Testing

Manual testing checklist:

- Load the page and verify the first question appears.
- Submit a correct answer and confirm the correct score increments.
- Submit an incorrect answer and confirm the incorrect score increments.
- Resize the browser to verify the layout adapts.
